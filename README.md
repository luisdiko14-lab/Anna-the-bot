# Anna Modular Bot + Command Builder

This project is a modular Discord bot built with `discord.py`.

## Setup
1. Copy `.env.example` to `.env` and add your `BOT_TOKEN`.
2. Install dependencies: `pip install -r requirements.txt`.
3. Run the bot: `python client/dashboard_bot.py`.

## Command Builder
Access the web UI via the `!commandbuilder` command or by opening `web/index.html` in your browser.

## Features
- **Modular Cogs**: Moderation, Fun, Utilities, and Commands Manager.
- **Custom Commands**: Create and persist commands via JSON.
- **Web UI**: Local dashboard for command creation.
